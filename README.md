# Cyber Activity Monitor

## Overview

Cyber Activity Monitor is an educational Python application developed as part of the SkillCraft Technology Cyber Security Internship.

This project demonstrates Python programming concepts through a menu-driven application that includes:

- Text Analysis
- Password Strength Evaluation
- Keyboard Shortcut Guide
- Activity Logging

The application focuses on improving Python programming skills while promoting cybersecurity awareness and secure coding practices.

---

## Features

- Text Analyzer
  - Character Count
  - Word Count
  - Uppercase Letters
  - Lowercase Letters
  - Digits
  - Spaces
  - Special Characters

- Password Strength Checker
  - Minimum Length Check
  - Uppercase Validation
  - Lowercase Validation
  - Digit Validation
  - Special Character Validation

- Keyboard Shortcut Guide
  - Copy
  - Paste
  - Cut
  - Undo
  - Redo
  - Save
  - Select All

- Activity Logger
  - Stores user activity
  - Saves date and time
  - Uses file handling
