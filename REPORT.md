# PROJECT REPORT

## Project Title

Cyber Activity Monitor

---

## Objective

The objective of this project is to create an educational Python application that demonstrates text analysis, password evaluation, keyboard shortcut awareness, and activity logging using file handling.

---

## Modules

### Module 1 – Text Analyzer

Analyzes user-entered text and displays:

- Character Count
- Word Count
- Uppercase Letters
- Lowercase Letters
- Digits
- Spaces
- Special Characters

---

### Module 2 – Password Strength Checker

Checks whether a password satisfies common security requirements.

Parameters checked:

- Minimum Length
- Uppercase Letter
- Lowercase Letter
- Digit
- Special Character

---

### Module 3 – Keyboard Shortcut Guide

Displays commonly used keyboard shortcuts for productivity.

Examples:

- Ctrl + C
- Ctrl + V
- Ctrl + X
- Ctrl + Z
- Ctrl + Y
- Ctrl + S
- Ctrl + A

---

### Module 4 – Activity Logger

Stores module usage information in **activity_log.txt** together with the current date and time.
